# truck-trip-calculator
Python CLI script to calculate truck trip profit based on distance, fuel price, and cargo rate.
# Truck Trip Calculator / Калькулятор рейса

Простой скрипт на Python для расчёта чистой прибыли с рейса грузовика. 

## Проблема
При планировании рейса водителю или логисту нужно быстро посчитать, окупится ли поездка с учётом цены топлива и ставки за перевозку. Считать вручную долго и легко ошибиться.

## Решение
Скрипт запрашивает дистанцию, цену топлива и ставку. На основе расхода топлива (по умолчанию 30 л/100 км) он вычисляет затраты и показывает чистую прибыль. Все расчёты автоматически записываются в лог-файл `logistic.txt`.

## Как запустить
1. Установите Python.
2. Скачайте файл `calculate_logitst.py`.
3. Запустите в терминале:
```bash
python calculate_logitst.py
